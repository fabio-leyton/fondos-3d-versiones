# Fondos 3D — versiones

Aquí solo se publican las versiones de la app **Fondos 3D** (fondos de pantalla animados con efecto 3D para
Android 11 o más nuevo). El código no está en este repositorio.

- **Descargar**: la APK de la última versión está en [Releases](../../releases/latest).
- **Actualizar**: la app avisa sola cuando hay una versión nueva (desde la 0.6.0). Tus fondos no se borran.
- `version.json`: la versión más reciente; la app lo consulta para avisar.
